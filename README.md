# deepagents-in-action-study

Deep Agents 实战课程学习笔记与实验记录，基于 datawhalechina/deepagents-in-action 开源教程，DataWhale 组队学习。

## 课程来源

- 课程仓库：[datawhalechina/deepagents-in-action](https://github.com/datawhalechina/deepagents-in-action)
- 在线教程：[Deep Agents 实战](https://datawhalechina.github.io/deepagents-in-action/)
- 课程作者：沧海九粟及课程贡献者。

## 学习记录

按照学习任务整理笔记、实验代码、运行结果与问题排查记录，使用 `task0`、`task1` 等目录保存对应任务的材料。

实验记录注明课程章节、依赖版本、模型名称、运行方式和实际验证结果。API 密钥与个人配置保存在本地 `.env` 文件中。
